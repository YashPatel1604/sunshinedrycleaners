# Images Folder

This folder contains all images used on the Sunshine Dry Cleaners website.

## Required Images

### Logo
- **File name**: `logo.svg` (or `logo.png`/`logo.jpg`)
- **Recommended format**: SVG (best quality and scalability)
- **Recommended size**: 200x50px (or similar aspect ratio)
- **Supported formats**: SVG (recommended), PNG, JPG
- **Usage**: Displayed in the navigation bar

## Optional Images

You can add additional images here for:
- Hero section images
- Service images
- Blog post images
- Gallery images
- Any other website assets

## Notes

- The logo file (`logo.svg`) should be placed directly in this `images/` folder
- If the logo is not found, the website will display a text fallback: "☀️ Sunshine Dry Cleaners"
- **SVG is recommended** for logos as it scales perfectly at any size and typically has smaller file sizes
- If using PNG/JPG, use a transparent background for best results
- Optimize images for web use to ensure fast loading times
